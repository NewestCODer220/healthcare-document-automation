# Sample Output Description

The final output of this project is a completed service planning document generated from structured assessment data.

For privacy reasons, this repository does not include real patient documents or protected health information.

A typical generated document includes:

- Recipient demographic information
- Assessment-based service details
- Care team information
- Medication-related fields when applicable
- Goal-related information
- Editable text fields for staff review
- Locked formatting to preserve document structure
