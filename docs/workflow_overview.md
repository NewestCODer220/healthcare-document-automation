# Workflow Overview

This project automates a healthcare document workflow by moving information through the following process:

1. Assessment PDFs are reviewed and processed.
2. Python extracts relevant structured data from the PDFs.
3. Extracted data is organized into an Excel workbook.
4. VBA and Mail Merge generate individualized service planning documents.
5. Documents are formatted consistently while keeping required text fields editable.
6. Final documents are prepared for review and distribution.

## Process Flow

Assessment PDF  
↓  
Python Data Extraction  
↓  
Excel Data Organization  
↓  
VBA / Mail Merge Automation  
↓  
Formatted Service Planning Documents  
↓  
Review and Distribution
